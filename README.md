# Venta directa: heladera y aire acondicionado

Página estática en español para mostrar los productos, consultar sus datos y coordinar visitas por WhatsApp.

## Incluye

- Inicio con tres opciones: ver la heladera, ver el aire acondicionado o contactar directamente.
- Fichas con precios, características, detalles de uso y fotos originales optimizadas para web.
- Galerías navegables y fotos ampliables.
- Botones de WhatsApp con mensajes preparados para cada producto.
- Diseño adaptable a teléfonos y computadoras. No requiere instalar dependencias.

## Publicar con GitHub Pages

1. Abrí **Settings** en este repositorio.
2. En el menú lateral, entrá a **Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/ (root)`; guardá los cambios.
5. Esperá a que GitHub Pages publique el sitio. La URL aparecerá en esa misma sección.

Cada nuevo cambio en `main` se reflejará en el sitio publicado.
